# DevSecOps Quickstart

1. Push this repo to GitHub.
2. Enable branch protection, secret scanning, Dependabot, and CodeQL.
3. Add GitHub Actions repository variables and secrets listed in `docs/devsecops_runbook.md`.
4. Run the `infra-iac` workflow.
5. Run the `app-build-scan-push-deploy` workflow.
6. Demonstrate Git commit history, pull request checks, code scanning, IaC scanning, image scanning, ECR image tag, and Kubernetes deployment.
